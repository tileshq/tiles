# ADR-038: Tiles splits into a public repository under FSL-1.1-ALv2, a private design repository and a private paid repository; the official binary carries the house design pack sealed

- Status: Accepted; supersedes [ADR-019](ADR-019-copying-without-company-data.md)'s closed source and its "no published source" layer; extends [ADR-036](ADR-036-design-pack-seam-and-deterministic-seal.md) and [ADR-037](ADR-037-plain-theme-for-builds-from-source.md), which built the seam and the plain theme this split needs; its trademark search before the public launch is superseded by [ADR-040](ADR-040-licence-cla-and-trademark-files.md), which parks the search until Tiles has paying customers; its cut, the public release and the end of the releases-only repository in the public tree are [ADR-059](ADR-059-public-cut.md)'s
- Date: 2026-10-20

## Context

ADR-019 kept Tiles closed: no published source, installs from a releases-only repository, and the forms and tokens sealed inside the binary. On 2026-10-19 the owner decided to publish the terminal product and keep the design and the paid data layer private, and settled nine questions on how.

Three facts shaped the answers. The chart craft lives in the engine code (`crates/tiles-engine/src/layout/` implements every card rule, and `tests/rules.rs` asserts them by rule id), so publishing the engine publishes how Tiles draws; what can stay private is the values and colours in the house `tokens.json`, the playbook that states them, and the images drawn with them. The forms cannot be private in practice: their summaries go into the tool schema every model reads (`crates/tiles-intent/src/schema.rs`) and `tiles forms` prints them. And code cites ADRs by number in more than three hundred places, so the public repository has to keep the numbers.

## Decision

- **Three repositories.** `tiles` is public and holds the terminal product: the intent, the engine, the terminal output, the MCP server, the CLI, the harness add-ons, the Omni connector, the forms, the fonts, the plain theme, the fuzz targets and the formal proofs. `tiles-design` is private and holds the house design pack: the house `tokens.json`, the playbook with its values, the goldens and prototype references drawn with them, and the tool that seals the pack. `tiles-pro` is private and paid: the BigQuery and dbt source (`tiles-warehouse`), later paid features, and the paid binary's entry crate, built from the public repository's tags.
- **The public repository is canonical** for every open path. Outside pull requests land there. `tiles-pro` depends on the public crates at a tag and carries its own `deny.toml` that allows exactly the public repository's URL, since the definition of done forbids git dependencies here.
- **Licence: FSL-1.1-ALv2.** Anyone may read, run, change and use Tiles, inside a company included; nobody may offer it, or something substituting for it, as a competing commercial product or service. Each version becomes Apache-2.0 two years after it is published. Tiles is described as "source-available" or "Fair Source", never "open source". `Cargo.toml` declares `LicenseRef-FSL-1.1-ALv2`, and `LICENSE` carries the FSL text before the public cut; the Inter and pstack notices stay beside it.
- **A contributor licence agreement.** A contributor signs once, on their first pull request, granting a copyright and patent licence with the right to relicense, so their code can ship in the official binary beside the sealed pack and in the paid build. A DCO sign-off alone grants neither.
- **The official binary carries the house design sealed.** Official releases build the public source with the pinned design pack (ADR-036), under a separate Tiles Design Licence that allows the pack only inside an unmodified official binary. A build from source draws the plain theme (ADR-037). `tiles --licence` names all three licences. With the source public, the seal stops `strings` and a JSON scan, and the design licence forbids the rest.
- **Forms and fonts are public.** The 17 form files are the intent contract every model already reads. The fonts are Inter under the SIL Open Font License.
- **The Omni connector is open.** It reads a semantic layer the user already licenses, with the user's own key, and its HTTP and credential code gains most from public review.
- **BigQuery and dbt are private and paid.** `tiles-warehouse` moves to `tiles-pro` at the cut; the public crates keep the source seam it registers through ([ADR-031](ADR-031-warehouse-sources.md), [ADR-034](ADR-034-warehouse-surface.md)).
- **One fresh root commit.** The public repository starts from one commit of a cleaned tree. The private repository it was cut from keeps the full history as the archive and is never made public itself, since its history, pull request conversations and early releases hold material the public tree does not.
- **The records keep their numbers.** Every ADR goes public under its own number, edited in place to drop private detail. A decision that changes still takes a new record.
- **`install.sh` downloads with curl.** `scripts/install.sh` no longer calls `gh`. It reads the latest tag from the redirect of `https://github.com/<repo>/releases/latest` and downloads the archive and `SHA256SUMS` from `https://github.com/<repo>/releases/download/<tag>/` with curl over HTTPS only, where `<repo>` is `TILES_RELEASES_REPO`, else `TILES_REPO`, else this repository. Installing needs no GitHub sign-in. `tiles update` keeps its `gh` path ([ADR-032](ADR-032-update-command-and-harness-versions.md)). This supersedes [ADR-022](ADR-022-sealed-assets-and-releases-only-channel.md)'s download with `gh`.
- **The name is not searched before launch** (corrected by [ADR-040](ADR-040-licence-cla-and-trademark-files.md)). No trademark attorney searches the name before the public launch; a search and a filing come once Tiles has paying customers, and the launch does not wait on them. `TRADEMARKS.md` asks forks to rename and allows "built with Tiles".

## Consequences

- The definition of done keeps refusing GPL, AGPL and LGPL dependencies: the official binary links the proprietary design pack and the paid build links closed crates, and neither may be pulled under a copyleft licence.
- A copy rewritten from scratch without the source is not stopped by any licence; the trademark and the paid data layer carry that case.
- At the cut these leave the public tree: `crates/tiles-engine/assets/tokens.json`, `docs/playbook.md`, `crates/tiles-engine/tests/golden/`, `crates/tiles-engine/tests/reference/` with `tests/reference.rs`, `scripts/test-house.sh` and the `house` CI job, the golden-reference and theme-port tools under `tools/`, and `crates/tiles-warehouse`. `scripts/check-docs.py` then checks `docs/card-rules.md` alone.
- Rulesets, branch protection and private vulnerability reporting, unavailable on a private repository under GitHub Free, work on the public one, as do free macOS CI minutes.
- Installs and `tiles update` read this repository's releases, which `RELEASES_REPO` names; `TILES_RELEASES_REPO` points them elsewhere.
