# ADR-040: Tiles ships the FSL text, a design licence for the house pack alone, a CLA collected by CLA Assistant and a trademark notice; the trademark search waits for paying customers

- Status: Accepted; supersedes [ADR-038](ADR-038-open-core-split.md)'s trademark search before the public launch and [ADR-036](ADR-036-design-pack-seam-and-deterministic-seal.md)'s Tiles Design Licence line for a build from source; carries out ADR-038's licence, CLA and design licence
- Date: 2026-10-20

## Context

ADR-038 chose FSL-1.1-ALv2 for the public source, a contributor licence agreement, a separate Tiles Design Licence for the sealed house pack, and an attorney's search of the name before the public launch. None of the texts existed: `LICENSE` still reserved every right, and `tiles --licence` called the code and design licences placeholders.

The trademark search was then parked: Tiles has no paying customers yet, and the public launch does not wait on a search or a filing.

The commit and pull request convention lived only in the pull request template and in agents' instructions, and the template's "Built with" line was optional. Outside contributors need the convention where they look for it.

## Decision

- **`LICENSE` is the FSL text.** It is the canonical FSL-1.1-ALv2 template from https://fsl.software/FSL-1.1-ALv2.template.md, verbatim, with the year (2026) and the licensor (the owner) filled in. Below it, under its own heading, `LICENSE` says that official releases also carry the design pack under `LICENSE-design`, and keeps the notices for Inter (SIL Open Font License 1.1) and the vendored pstack and emil-skills skills (MIT).
- **`LICENSE-design` is the Tiles Design Licence.** It covers the house design pack alone: its tokens, the sealed pack and the cards drawn with them. The pack may be run only inside an unmodified official release; nobody may extract, decrypt, modify or redistribute it outside one, or reproduce its tokens in another product. Those limits do not apply to the cards and images an official release draws for a user, who may keep, use and share them anywhere. The plain theme a build from source draws ([ADR-037](ADR-037-plain-theme-for-builds-from-source.md)) is part of the code, under FSL. So `tiles --licence` names the Tiles Design Licence only for a build that took a pack (`Design pack <n>: the Tiles Design Licence (LICENSE-design)`), and a build from source reads `Design assets (built from source): the plain theme, under the code's licence`. Neither line says placeholder. Release tarballs and the macOS package carry `LICENSE-design` beside `LICENSE`.
- **The CLA is `.github/CLA.md`**, an individual agreement modelled on the Apache Individual Contributor License Agreement: the contributor keeps their copyright and grants a copyright and patent licence with the right to relicense, so their code can ship under FSL, in the official binary beside the pack, and in the paid build.
- **CLA Assistant asks for it.** The hosted CLA Assistant (cla-assistant.io) asks each contributor once, on their first pull request, records the signature and sets a status check. It is free and needs no workflow and no secret in this repository. CLA Assistant Lite, the GitHub Action configured from a file in the repository, was refused because it needs a `pull_request_target` workflow with write access, which this repository does not allow. So the bot's configuration does not live in `.github/`, as first planned: only the agreement text does, in `.github/CLA.md`, and the bot is configured in the CLA Assistant dashboard, which links the repository to a gist holding the agreement, kept identical to `.github/CLA.md`. That link is made when the public repository exists.
- **`TRADEMARKS.md` asks forks to rename.** A fork or any build that is not an official release must go by another name; "built with Tiles" and naming Tiles to describe or compare it are fine. FSL's trademark clause already grants no right to the name.
- **No trademark search before launch.** No attorney searches the name before the public launch. A search and a filing come once Tiles has paying customers, and the launch does not wait on them.
- **The contribution rules are written down.** `CONTRIBUTING.md` lists the checks CI runs, the CLA, the rule that a changed decision takes a new record, and the rule that golden baselines are re-blessed only for an intended visual change ([ADR-006](ADR-006-quality.md)). It sets the commit convention: `type(scope): summary` with the types `feat`, `fix`, `perf`, `refactor`, `docs`, `test`, `build`, `ci` and `chore`, a required scope, an imperative lowercase summary with no trailing period, at most 72 characters and one user-visible outcome; a body that says why and names the ADR, without narrating the work, quoting conversations or naming local paths; a `Co-authored-by:` trailer for the model when an agent wrote the change; and squash merges whose commit is the pull request's title with `(#N)` and whose body is its Change section followed, when an agent wrote the change, by a `Co-authored-by:` trailer naming the model, which whoever merges adds, leaving out the branch's fix-up commits, which are not held to the subject convention. The pull request template's "Built with" line, naming the model and harness, is filled in on every pull request, and the definition of done's first point says so.
- **Security reports go to GitHub first.** `SECURITY.md` names GitHub's private vulnerability reporting on the public repository first and the email second, and supports the latest release on the public repository, with the releases-only repository until the first public release. The issue templates ask a bug report for `tiles --version` and the `tiles check` output, take harness or terminal requests and chart form requests, and send security reports to the private form.

## Consequences

- A later search may find a conflict that forces a rename after launch; the launch takes that risk. Until a mark is filed, `TRADEMARKS.md` rests on FSL's trademark clause and the name's use.
- The issue templates' security link names `tileshq/tiles`, the public repository; if it moves, `.github/ISSUE_TEMPLATE/config.yml` changes with it.
